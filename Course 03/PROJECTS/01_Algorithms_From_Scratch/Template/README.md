# ML Algorithms from Scratch Template

## How to Use

1. **Copy the template** to your project folder
2. **Use only NumPy** - no scikit-learn for implementations
3. **Fill in the functions** - implement the logic marked with TODO
4. **Test incrementally** - test each algorithm separately
5. **Compare with scikit-learn** - verify your implementation

---

## Implementation Order

1. **Linear Regression** - Start with simplest algorithm
2. **Logistic Regression** - Add sigmoid activation
3. **PCA** - Implement dimensionality reduction
4. **Testing** - Compare with scikit-learn

---

## Tips

- Use only NumPy (no scikit-learn for core algorithms)
- Test with small datasets first
- Visualize gradient descent convergence
- Compare results with scikit-learn for verification
