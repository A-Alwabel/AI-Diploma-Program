# Gradient Descent Visualizer Template

## How to Use

1. **Copy the template** to your project folder
2. **Install matplotlib:** `pip install matplotlib`
3. **Fill in the functions** - implement the logic marked with TODO
4. **Run visualizations** - see gradient descent in action
5. **Compare variants** - batch vs SGD vs mini-batch
