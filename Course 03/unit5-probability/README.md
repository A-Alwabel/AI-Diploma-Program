# Unit 5: Probability, Sampling, and Statistical Inference

**Official hours:** 14 (theory+practical)

Machine learning models make predictions under uncertainty, and probability is the language of uncertainty. This unit covers distributions, sampling, estimation (including MLE), Bayesian inference, and hypothesis testing — and connects each of them to ML practice.

---

## Prerequisites

- Unit 3: Optimization and Statistical Foundations for ML (basic statistical measures)
- Comfortable with functions, summation notation, and NumPy
- Repo-root `.venv` active and the **ai-diploma** Jupyter kernel selected

---

## Learning Objectives

By the end of this unit, you will be able to:

- Work with common probability distributions in Python
- Apply the central limit theorem with simulations
- Perform sampling and point estimation
- Implement maximum likelihood estimation (MLE) for different distributions
- Apply Bayesian inference methods
- Implement hypothesis testing procedures and compute p-values and confidence intervals
- Connect probability theory to ML model implementations
