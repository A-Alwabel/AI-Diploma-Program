## Project Overview

Create a knowledge-based system using rule-based reasoning to solve a specific domain problem.

---

## Learning Objectives

- Design a knowledge base
- Implement rule-based reasoning
- Create an inference system
- Apply to a real-world domain

---

## Requirements

### Functional Requirements
- Knowledge base with facts and rules
- Inference engine (forward or backward chaining)
- Query interface
- Explanation capability

### Technical Requirements
- Python 3.8+
- Clear rule representation
- Documentation

---

## Deliverables

1. Knowledge base implementation
2. Inference engine code
3. Example queries and results
4. Documentation
