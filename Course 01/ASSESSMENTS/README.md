# Assessments
## AIAT 111 - Introduction to Artificial Intelligence and Applications

This folder holds the course-level assessment. Take it after completing Units 1–5.

| File | What it is |
|------|------------|
| `Final_Exam.md` | Final exam: 2 hours, 100 points, covering all five units |

Unit quizzes are separate — one per unit, inside each unit's `quizzes/` folder (see `../QUIZZES/README.md`). Projects are graded from `../PROJECTS/`.

Answer keys are released by your instructor.
