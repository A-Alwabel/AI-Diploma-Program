# Unit 1: Introduction to AI and Applications

**Course:** AIAT 111 · **Unit hours:** 12 (6 theory + 6 practical)

What AI is and where it came from; intelligent agents and rationality; the philosophy of AI and the Turing Test; classic search algorithms (uninformed, heuristic, adversarial); knowledge representation; Python basics for AI; and a first look at generative AI.

**Prerequisites:** None — this is the first unit of the first course. Complete the setup in `../START_HERE.md` before starting.
