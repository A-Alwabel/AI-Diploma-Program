# Project 01 – Starter code
## Optional starting point for Image Classification System

**Use this only if you want a skeleton.** You can also start from scratch following the main project README.

---

## Contents

- **`train_stub.py`** – Minimal training script: load data (e.g. CIFAR-10 or MNIST), build a small CNN, train for a few epochs, save model. Replace with your dataset and architecture.
- **`predict_stub.py`** – Load saved model and run inference on a few images; print predictions. Adapt for your model path and input format.

## How to use

1. Copy `train_stub.py` and `predict_stub.py` to your project folder (e.g. `notebooks/` or project root).
2. Install: `pip install tensorflow numpy` (or `torch torchvision` if you prefer PyTorch).
3. Run training: `python train_stub.py` (edit data path and model as needed).
4. Run inference: `python predict_stub.py` (edit model path and image path).
5. Expand with your own data, augmentation, transfer learning, and API as per the project rubric.
