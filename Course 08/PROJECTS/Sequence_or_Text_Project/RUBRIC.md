# Optional Project 02 – Rubric
## Sequence or Text Model

**Total: 100 points** (if used by instructor). Adjust weights per your course policy.

| Section | Points | Criteria |
|---------|--------|----------|
| Data loading and preprocessing | 20 | Correct load, split, tokenization/normalization; train/val/test |
| Model design | 25 | Appropriate architecture (RNN/LSTM/Transformer); correct head for task |
| Training and validation | 20 | Training loop; validation monitoring; model saved |
| Evaluation and report | 20 | Metrics (accuracy/F1 or MSE); short report with results and limitations |
| Code quality and optional deployment | 15 | Readable code; optional API or demo |
| **Total** | **100** | |

**Instructor note:** This project is optional. Use it for students who want a second capstone (e.g. NLP or time series) alongside Project 01 (Image Classification).
