# Projects
## AIAT 122 — Deep Learning

Capstone projects, assigned by your instructor.

| Project | Folder | Task | Best started after |
|---------|--------|------|--------------------|
| 01 — Image Classification System | `Image_Classification_System/` | Build and deploy an image classifier (CNN or transfer learning) | Unit 2 (and Unit 5 for deployment) |
| 02 — Sequence or Text Model | `Sequence_or_Text_Project/` | Sentiment analysis, text classification, or time-series forecasting | Unit 3 (and Unit 5 for deployment) |

Each project folder contains:

- `README.md` — objective, steps, deliverables, and submission instructions.
- `PROJECT_GUIDE.md` — step-by-step walkthrough with code snippets.
- `RUBRIC.md` — grading criteria.
- `starter/` — optional starter scripts (`train_stub.py`, `predict_stub.py`).

`project_template.md` is a generic template for structuring project reports.
