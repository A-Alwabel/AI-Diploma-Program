Credit hours: 3 · Contact hours: 4/week · Total training hours: 64 (theory+practical)

## Prerequisites

- Semester 1 (AIAT 111–116) completed, including machine learning fundamentals.
- Comfortable with Python and NumPy.

---

## Setup (once)

1. Use the repo root `.venv` and select the **"ai-diploma"** Jupyter kernel in notebooks.
2. Notebooks that import **TensorFlow** run on the **"tfenv"** kernel instead; **PyTorch** notebooks use "ai-diploma". This course uses both frameworks.
3. Course-specific dependency notes: `DOCS/REQUIREMENTS_COURSE_08.md`.
4. No GPU? Use Google Colab for free GPU: `DOCS/COLAB_SETUP.md`.

---

## The path

Follow this order — nothing else is required:

1. Read the course `README.md` (overview, units, CLOs).
2. **Unit 1** `unit1-deep-learning-basics/` — read its README, run `examples/` notebooks in file order (01, 02, 03, …), do `exercises/`, take `QUIZZES/quiz_01.md`.
3. **Unit 2** `unit2-cnns/` — same pattern, then `QUIZZES/quiz_02.md`.
4. **Unit 3** `unit3-rnns-transformers/` — same pattern, then `QUIZZES/quiz_03.md`.
5. **Unit 4** `unit4-advanced-dl/` — same pattern, then `QUIZZES/quiz_04.md`.
6. **Unit 5** `unit5-deployment/` — same pattern, then `QUIZZES/quiz_05.md`.
7. **ASSESSMENTS/** — theory exam, practical exam, and final exam, as scheduled by your instructor.

Projects (`PROJECTS/`) and the case study (`CASE_STUDIES/`) are assigned by your instructor.

**Order rule:** in each unit, always follow the notebook **file numbers** (01 → 02 → 03 …). Slide numbers mentioned inside notebooks are topic references only.
