# Assessments
## AIAT 122 — Deep Learning

Course-level exams, taken after finishing Units 1–5 and as scheduled by your instructor.

| Exam | File | Format |
|------|------|--------|
| Theory exam | `Theory_Exam_1Hour.md` | 60 minutes, 40 points |
| Practical exam | `Practical_Exam_1Hour.md` | 60 minutes, 40 points, Python + PyTorch |
| Final exam | `Final_Exam.md` | 2 hours, covers the whole course |

Each exam file states its own instructions and marking scheme at the top.

Answer keys and grading rubrics are released by your instructor.
