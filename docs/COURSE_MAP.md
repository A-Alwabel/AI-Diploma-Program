## 🎯 Why Topics Appear in Multiple Courses

### 1. **Spiral Curriculum Approach**
Topics are introduced multiple times with increasing depth:
- **Level 1 (Introduction):** Conceptual overview, "what it is"
- **Level 2 (Deep Dive):** Full coverage, "how it works"
- **Level 3 (Application):** Practical use, "when to use it"

### 2. **Different Perspectives**
Same topic, different focus:
- **Course 01:** Conceptual understanding
- **Course 04:** Algorithm implementation
- **Course 05:** Data science application
- **Course 08:** Deep learning specialization

### 3. **Prerequisites and Foundations**
Some topics appear early as prerequisites:
- **Course 01** introduces concepts needed for later courses
- **Course 03** provides math foundations for all courses

**Unit-level prerequisites:** Each unit’s “Prerequisites Checklist” (in the unit folder `README.md`) and the official **Unit ↔ Folder / Notebook / Module** mappings (in each course `README.md`) align with `DETAILED_UNIT_DESCRIPTIONS.md`. For cross-course foundations (e.g. Course 02 Unit 4 ↔ Course 03), see the course `START_HERE.md` and the tables below.

## 🗺️ Learning Paths

### Path 1: Complete Beginner
```
1. Course 01 (Introduction to AI)
2. Course 02 (Python for AI) - Learn Python properly
3. Course 03 (Mathematics) - Get math foundations
4. Course 04 (Machine Learning) - Learn ML
5. Course 05 (Data Science) - Apply ML
6. Continue with Semester 2...
```

### Path 2: Know Python Already
```
1. Course 01 (Introduction to AI) - Skip Python parts
2. Course 03 (Mathematics) - Get math foundations
3. Course 02 (Python for AI) - Focus on AI-specific Python
4. Course 04 (Machine Learning) - Learn ML
5. Course 05 (Data Science) - Apply ML
6. Continue with Semester 2...
```

### Path 3: Know Math Already
```
1. Course 01 (Introduction to AI)
2. Course 02 (Python for AI)
3. Course 04 (Machine Learning) - Skip Course 03 or review
4. Course 05 (Data Science)
5. Continue with Semester 2...
```

```
1. Course 01 (Quick review)
2. Course 03 (Math review)
3. Course 04 (ML - main focus)
4. Course 08 (Deep Learning - main focus)
5. Course 12 (Capstone - apply everything)
```

## ✅ Quick Decision Guide

**"Which course should I use for [Topic]?"**

1. **First time learning?** → Use the "Introduction" course
2. **Need full understanding?** → Use the "Deep Dive" course
3. **Need to apply it?** → Use the "Application" course
4. **Not sure?** → Start with introduction, then move to deep dive

**"I've seen this topic before, should I skip it?"**

- ❌ **Don't skip** - Each appearance adds depth
- ✅ **Review quickly** if you're confident
- ✅ **Focus on new aspects** in each appearance
