# Templates (Instructor Only)

These files are **templates for instructors** preparing units, exercises, and
assessments:

- `UNIT_MASTERY_TEMPLATE.md` — scaffold for a unit's mastery structure
- `EXERCISE_ENHANCEMENT_TEMPLATE.md` — scaffold for upgrading an exercise

**Students should not use these directly.** The student path is the numbered
one inside each course: `START_HERE.md` → examples → exercise → quiz →
assessment.

If you are preparing student materials, copy the template into the target
course/unit and replace all placeholders like `[Unit Name]`, `[concept]`, and
`[skill]`.
