## Step 1: Setup

This course uses the shared environment at the repository root — you do not install anything per course.

1. From the repository root, activate the virtual environment:

   ```bash
   # macOS/Linux
   source .venv/bin/activate
   # Windows
   .venv\Scripts\activate
   ```

2. Open notebooks in Jupyter and select the **ai-diploma** kernel.

If a notebook fails to import a library, make sure you selected the **ai-diploma** kernel, not a system Python.

## Step 2: Check Prerequisites

You should have completed the earlier Semester 1 courses (AIAT 111–115), and in particular be comfortable with:

- Basic Python (variables, functions, classes)
- Introductory ML concepts (training data, models, evaluation metrics)
