# Bias Audit Tool Template

## How to Use

1. **Copy the template** to your project folder
2. **Install fairlearn:** `pip install fairlearn`
3. **Fill in the functions** - implement the logic marked with TODO
4. **Test with sample data** - verify fairness metrics
5. **Generate audit report** - document findings
