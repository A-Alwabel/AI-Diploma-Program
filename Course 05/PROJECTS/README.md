# Projects Overview

Project materials for AIAT 115 - Scalable Data Science. **Project 01 is the course capstone**; Projects 02 and 03 are optional extensions.

---

## Project 01: Data Science Pipeline (Capstone)

**Topic:** End-to-end data processing
**Folder:** `01_Data_Pipeline/`

Build a scalable data processing pipeline using pandas, Dask, and RAPIDS for handling large datasets. This is the course capstone - complete it after finishing all five units.

[View details](01_Data_Pipeline/README.md)
