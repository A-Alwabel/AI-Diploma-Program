# Unit 3: Data Visualization

**Unit hours:** 19 (of 96 total training hours)

## Prerequisites

- Unit 2: Data Cleaning and Preparation (`../unit2-cleaning/`)
- Comfortable with pandas and basic data summaries

## What This Unit Covers

Communicating data visually: chart types and when to use them, Matplotlib fundamentals, statistical plots with Seaborn, interactive visualizations and dashboards with Plotly, customization/annotation for presentations, and visualization best practices for data storytelling.

## Examples (run in order)

| # | Notebook | Description |
|---|----------|-------------|
| 01 | `examples/01_chart_types_matplotlib_seaborn.ipynb` | Creating various chart types with Matplotlib and Seaborn |
| 02 | `examples/02_matplotlib_basics.ipynb` | Matplotlib fundamentals: figures, axes, subplots, styling |
| 03 | `examples/03_seaborn_plots.ipynb` | Statistical plots with Seaborn (distributions, categories, relationships) |
| 04 | `examples/04_plotly_interactive.ipynb` | Interactive Plotly charts |
| 05 | `examples/05_interactive_visualizations_plotly.ipynb` | Building interactive visualizations and dashboard-style figures with Plotly |
| 06 | `examples/06_customizing_annotating_visualizations.ipynb` | Customizing and annotating charts for presentations |
| 07 | `examples/07_visualization_best_practices.ipynb` | Visualization best practices for data storytelling |
| 08 | `examples/08_advanced_visualization_types.ipynb` | Advanced visualization types (heatmaps, pair plots, 3D) |

The `.png` and `.html` files in `examples/` are outputs generated by these notebooks.
