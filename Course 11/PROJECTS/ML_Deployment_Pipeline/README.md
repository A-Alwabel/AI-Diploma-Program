# ML Deployment Pipeline
## Course 11 (AIAT 125)

Deploy a trained ML model end to end with CI/CD. Assigned by your instructor.

## Scope

Apply the course workflow to one model of your choice:

1. Package the trained model (pickle/joblib or ONNX)
2. Serve it through a REST API (FastAPI or Flask)
3. Containerize the service with Docker
4. Add a CI/CD step (build, test, deploy)
5. Add basic monitoring (logging, drift check)

Use [`../project_template.md`](../project_template.md) for the project brief and the Unit 4 `examples/app/` folder as a working reference.

## Submission

Your instructor sets the deliverables, format, and due date.
