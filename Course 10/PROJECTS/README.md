# Projects

## AIAT 124 - Generative Artificial Intelligence

- `Generative_AI_Application/` — course project: design and build a generative
  AI application. See its `README.md` for scope and deliverables.
- `project_template.md` — project requirements, deliverables, and evaluation
  rubric.

The project asks you to build a generative application with GANs, VAEs, or
diffusion models, so Units 1–3 cover the needed techniques. Submission dates
are set by your instructor.
