# Course 04 Projects

Applied projects for AIAT 114 - Machine Learning Algorithms and Applications. Complete at least one project by the end of the course.

---

## Folder Structure

Each project folder contains:

- `README.md` - project description, requirements, deliverables, evaluation criteria
- `PROJECT_GUIDE.md` - step-by-step implementation guide
- `Template/` - starter code with TODOs (plus its own `README.md`)

```
PROJECTS/
├── README.md (this file)
├── 01_ML_Pipeline/
├── 02_Classification_System/
└── 03_Regression_Analysis/
```

---

## Available Projects

### Project 01: Complete ML Pipeline

- **Topic:** End-to-end machine learning (data loading through evaluation)
- **Difficulty:** Intermediate · **Estimated time:** 3-4 weeks
- **Folder:** `01_ML_Pipeline/` - see [README](01_ML_Pipeline/README.md)

Build a complete pipeline: preprocessing, feature engineering, model training, and evaluation on a house-price style dataset.

### Project 02: Multi-Class Classification System

- **Topic:** Classification algorithms
- **Difficulty:** Intermediate · **Estimated time:** 2-3 weeks
- **Folder:** `02_Classification_System/` - see [README](02_Classification_System/README.md)

Build a classification system with multiple algorithms (logistic regression, decision trees, SVM) and compare their performance.

### Project 03: Advanced Regression Analysis

- **Topic:** Regression techniques
- **Difficulty:** Advanced · **Estimated time:** 3-4 weeks
- **Folder:** `03_Regression_Analysis/` - see [README](03_Regression_Analysis/README.md)

Implement and compare regression techniques (linear, Ridge, Lasso, polynomial) with hyperparameter tuning and cross-validation.

**Recommendation:** start with Project 01 if unsure; Project 03 assumes the most experience.

---

## Getting Started

1. Read the project's `README.md` and `PROJECT_GUIDE.md`
2. Use the `Template/` starter code as your base
3. Review the related unit notebooks as references
4. Build incrementally and test as you go

## Evaluation

Evaluation criteria are listed in each project's `README.md`. Key areas: functionality, code quality, documentation, model performance.

## Submission

- **Code:** all source files, organized
- **Documentation:** a README explaining your project
- **Results:** metrics and visualizations
- **Report:** brief explanation of approach and findings

Format: zip file (`Project_XX_YourName.zip`) or a repository link, as your instructor specifies.
