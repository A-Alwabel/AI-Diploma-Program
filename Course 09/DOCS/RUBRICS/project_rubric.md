# Project Rubric
## AIAT 123 - Reinforcement Learning

Total: 100 points

## 1. Problem Formulation (20 points)

- 0-5: Problem is vague or not clearly sequential
- 6-10: Basic formulation exists but key pieces are weak
- 11-15: State, action, and reward are mostly clear
- 16-20: Formulation is clear, justified, and well matched to RL

## 2. Baseline and Comparison (15 points)

- 0-5: No meaningful baseline
- 6-10: Baseline exists but comparison is weak
- 11-15: Baseline is clear and comparison is useful

## 3. RL Implementation (20 points)

- 0-5: Incomplete implementation
- 6-10: Partial implementation with major gaps
- 11-15: Working implementation with some limitations
- 16-20: Clear working implementation with reasonable choices

## 4. Training and Evaluation (20 points)

- 0-5: Little or no evaluation
- 6-10: Some results but weak interpretation
- 11-15: Training results are present and interpreted
- 16-20: Results are clear, compared, and thoughtfully analyzed

## 5. Explanation and Reflection (15 points)

- 0-5: Minimal explanation
- 6-10: Some reasoning but shallow
- 11-15: Clear explanation of decisions, limits, and improvements

## 6. Ethics / Safety Awareness (10 points)

- 0-3: Missing
- 4-7: Mentioned briefly
- 8-10: Specific and relevant to the chosen application
