# RL Game Agent
## Course 09 Capstone Project

Build a reinforcement learning agent for a game or game-like environment and
explain your design decisions clearly.

## Project Goal

This project is where the course comes together. You should demonstrate that you
can:

- formulate an RL problem
- choose a reasonable algorithm
- train and evaluate an agent
- explain what worked, what failed, and why

## Recommended Scope

Choose one of these paths:

1. **FrozenLake or Grid World**
   Best for a safer, smaller tabular project
2. **CartPole**
   Good for bridging from tabular thinking to function approximation
3. **Your own simple game environment**
   Acceptable if the environment is clearly defined and not too large

## Minimum Requirements

Your project must include:

- a clear problem statement
- state, action, and reward definitions
- one baseline approach
- one RL training approach
- training results and evaluation plots
- a short discussion of limitations and next improvements

## Milestones

### Milestone 1: Problem Formulation

- define the environment
- define the state space
- define the action space
- define the reward function
- explain why RL is appropriate

### Milestone 2: Baseline

- create a random or heuristic baseline
- report baseline behavior

### Milestone 3: RL Agent

- implement the chosen learning method
- train the agent
- track rewards over time

### Milestone 4: Evaluation

- compare the trained agent with the baseline
- explain whether learning improved performance
- discuss failure cases

### Milestone 5: Reflection

- what was hard?
- what would you improve?
- what safety or reward-design issue could appear in a real deployment?

## Deliverables

Submit:

1. implementation notebook or code
2. short report in markdown
3. training curves or equivalent plots
4. final explanation of state, action, reward, algorithm, and results

## Suggested Report Structure

Use this structure in your report:

1. Problem statement
2. Environment design
3. State, action, reward
4. Algorithm choice
5. Training setup
6. Results
7. Failure analysis
8. Future improvements
