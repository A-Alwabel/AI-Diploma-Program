# Projects

## AIAT 123 - Reinforcement Learning

Start the project after finishing Unit 5.

## Core project

- `RL_Game_Agent/README.md` — build a reinforcement learning agent for a game
  or game-like environment (FrozenLake, Grid World, CartPole, or your own
  simple environment) with a baseline, training results, and a written
  reflection.

## Optional

- `project_template.md` — a blank template you can adapt into your own RL
  application project.
