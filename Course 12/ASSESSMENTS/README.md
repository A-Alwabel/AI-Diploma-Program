# Assessments - AIAT 126 Graduation Project

The final assessment of this course is project-based: it evaluates your graduation project submission, not a timed written exam.

- [Final_Exam.md](Final_Exam.md) - the final evaluation: documentation review, technical implementation, results and evaluation, and presentation/defense.

Before this evaluation you should have finished Units 1-5, taken the five quizzes (see [../QUIZZES/README.md](../QUIZZES/README.md)), and prepared all deliverables listed in [../PROJECT_GUIDELINES.md](../PROJECT_GUIDELINES.md).

Grading and any answer keys are released by your instructor.
