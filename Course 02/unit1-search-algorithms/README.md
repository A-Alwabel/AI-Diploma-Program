# Unit 1: Course Introduction and Search Algorithms

**Course:** AIAT 112 - Python for Artificial Intelligence
**Unit hours:** 18 (6 theory + 12 practical)

## What This Unit Teaches

The unit sets up the Python toolchain used throughout the course (NumPy,
pandas, Matplotlib, and related libraries), then moves to classic AI search:
representing problems as graphs and implementing uninformed and informed
search algorithms (BFS, DFS, A*).

## Prerequisites

- AIAT 111 - Introduction to AI Applications and Concepts (Course 01)
- Basic Python: lists, dictionaries, loops, functions, classes
- Environment set up per `../START_HERE.md` (repo root `.venv`,
  **ai-diploma** kernel)

## Notebooks (work in this order)

> **Tiers:** **CORE** = taught live in class (max 2 per 3-hour session) · **HOMEWORK** = self-study, assigned around the live sessions · **ENRICHMENT** = optional extra, only if time allows.

1. **[CORE]** `examples/01_python_libraries_for_ai.ipynb` - Python libraries for AI:
   NumPy, pandas, and supporting libraries, with data loading and a simple ML
   workflow.
2. **[CORE]** `examples/02_search_algorithms.ipynb` - Implement and compare BFS, DFS,
   and A* on graphs and problem spaces.
3. **[ENRICHMENT]** `enrichment/E9_test_time_compute_measured.ipynb` - Test-time compute,
   measured: 30 real routing instances solved exactly by enumeration, then accuracy plotted
   against compute budget for three search policies - the curve that governs 2026 reasoning
   budgets. Non-examinable.
