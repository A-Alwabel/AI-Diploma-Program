# ML Classifier Template

## How to Use

1. **Copy the template** to your project folder
2. **Read the comments** - they explain what to implement
3. **Fill in the functions** - implement the logic marked with TODO
4. **Test incrementally** - test each step of the pipeline
5. **Customize** - add your own features and improvements

---

## Template Structure

The template includes:
- ✅ Data loading function
- ✅ Preprocessing function
- ✅ Data splitting function
- ✅ Model creation function
- ✅ Training function
- ✅ Evaluation function
- ✅ Visualization function
- ✅ Pipeline skeleton in main()

---

## Implementation Order

1. **Load Data** - Start with built-in dataset (Iris) for simplicity
2. **Preprocess** - Handle missing values, encoding, scaling
3. **Split Data** - Create train/test sets
4. **Create Models** - Initialize all three models
5. **Train** - Fit models on training data
6. **Evaluate** - Test on test data
7. **Visualize** - Create comparison charts

---

## Tips

- Start with Iris dataset (built-in, no file needed)
- Test each function individually
- Use print statements to debug
- Refer to Notebook 05 for ML examples
- Don't skip preprocessing - it's important!
