# Expert System Template

## How to Use

1. **Copy the template** to your project folder
2. **Read the comments** - they explain what to implement
3. **Fill in the functions** - implement the logic marked with TODO
4. **Test incrementally** - test each component as you complete it
5. **Customize** - add your own domain and features

---

## Template Structure

The template includes:
- ✅ Rule class - For IF-THEN rules
- ✅ KnowledgeBase class - For storing facts and rules
- ✅ Forward chaining function
- ✅ Backward chaining function
- ✅ ExpertSystem class - Main system

---

## Implementation Order

1. **KnowledgeBase** - Start here, implement basic structure
2. **Rule class** - Implement rule representation
3. **Forward Chaining** - Easier to implement first
4. **Backward Chaining** - More complex, implement after forward
5. **ExpertSystem** - Put it all together

---

## Tips

- Choose a simple domain first (weather, medical diagnosis)
- Start with a few facts and rules
- Test with simple queries
- Refer to Notebook 02 for knowledge representation examples
