# Pathfinding Game Template

## How to Use

1. **Copy the template** to your project folder
2. **Read the comments** - they explain what to implement
3. **Fill in the functions** - implement the logic marked with TODO
4. **Test incrementally** - test each function as you complete it
5. **Customize** - add your own features

---

## Template Structure

The template includes:
- ✅ Function signatures (what to implement)
- ✅ Docstrings (what each function should do)
- ✅ TODO comments (what to fill in)
- ✅ Example usage in main()

---

## Implementation Order

1. **Maze class** - Start here, implement basic maze structure
2. **BFS** - Easiest algorithm to implement
3. **DFS** - Similar to BFS but uses stack
4. **A*** - Most complex, implement last
5. **Visualization** - Make it look good!

---

## Tips

- Don't try to implement everything at once
- Test each function individually
- Use print statements to debug
- Refer to Notebook 01 for algorithm examples
